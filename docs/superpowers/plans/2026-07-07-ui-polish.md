# Sub-proyek E: UI Polish — Dark Mode, Tombol Simpan, Modal Ringkas, Font Struk 80mm — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Lima perbaikan UI kecil-menengah yang tidak punya dependensi cross-modul — fix dark mode di modal Piutang/Hutang, ganti label "Parkir" → "Simpan" di keranjang POS, ringkas modal edit barang, dan rutekan struk 80mm (Penjualan + SPK) via pipeline font embed supaya font branded tampil.

**Architecture:** Semua isu independen — bisa dijalankan paralel kecuali urutan commit. E1 & E2 murni Tailwind class audit/fix (tidak sentuh logika). E3 string label user-facing saja. E4 Tailwind class + struktur `<details>`. E5 routing cetak lewat pipeline yang sudah ada (`preparePrintHtml` → `openPrintDocument`), hapus inline print/iframe fallback di `thermal-print.ts` dan inline `<script>window.print()` di `spk-print.ts`.

**Tech Stack:** Next.js 15 (App Router, server actions), React 19, Tailwind CSS, Bahasa Indonesia untuk UI/komentar. Font cetak via `src/lib/print-embed-client.ts` (client) → `embedPrintFontsAction` (server action, `src/app/cetak/actions.ts`) → `embedGemiprintFontsInHtml` (`src/lib/print-fonts-server.ts`, base64 embed), lalu `openPrintDocument` (`src/lib/print-fonts.ts`, popup + `<base href>` + `printAfterAssetsReady`).

## Global Constraints

- Bahasa Indonesia untuk semua UI strings, komentar baru, pesan error. Framework/library terms boleh English.
- Dark mode wajib: setiap color class butuh pasangan `dark:`. Tidak boleh ada `border-gray-300`/`bg-white`/`bg-gradient-*-50`/`text-gray-*` tanpa pasangan `dark:` di kode yang diubah.
- E3: **hanya label user-facing** yang diubah ("Parkir" → "Simpan"). **Jangan rename** state (`showParkirModal`), fungsi (`handlePark`, `handleConfirm`), action (`parkCartAction`), atau prop (`onParkClick`) — churn tinggi tanpa nilai user.
- E5: **tidak mengubah** `preparePrintHtml` / `embedPrintFontsAction` / `openPrintDocument` / `print-fonts-server.ts` — pipeline ini sudah benar (dipakai Faktur A4). Hanya routing caller baru.
- `preparePrintHtml` adalah **client-safe** (file `src/lib/print-embed-client.ts` tidak pakai `"use server"`; ia memanggil server action `embedPrintFontsAction` via import biasa dari client component — Next.js menganggap itu server action call). Bisa di-import dari client component / page.
- `openPrintDocument(html, title, options?)` — signature: `html: string, title: string, options?: { autoPrint?: boolean }` → return `boolean`. Default `autoPrint: false` (popup dengan toolbar, user tekan Ctrl+P). Untuk struk 80mm, pakai default (tidak auto-print) supaya konsisten dengan Faktur A4 (`printFaktur` pakai `openPrintDocument(html, "Cetak faktur")` tanpa autoPrint).
- Nama font family di `@font-face` struk 80mm SAMA dengan yang di-embed server: `'Bauhaus 93'` (normal) dan `'TW Cen MT'` (normal + bold). Sudah cocok — jangan ubah family name.
- Verifikasi wajib selesai "done": `npm run type-check` (0 error) → `npm run build`. E1/E2/E3/E4 UI-only → boleh skip jest (iron rule 10: "UI-only changes may skip jest but still need type-check + build"). E5 perlu verifikasi manual (cetak struk, cek font branded).
- E1/E2/E4 perlu verifikasi dark mode visual manual (toggle dark mode di browser, buka modal terkait, cek kontras).
- Node 22 + npm. Icons: SVG components, jangan emoji.
